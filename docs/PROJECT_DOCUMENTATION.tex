\section{Project Overview}
\textbf{ajedrezUPV} is an AI chess project from UPV. Focus: decision algorithms, heuristic evaluation, game engine programming.

\subsection*{Key Features}
\begin{itemize}
    \item Custom chess engine (C++23)
    \item Alpha-Beta pruning algorithm
    \item UCI notation support
    \item Neural network integration
    \item Modular and extensible code
    \item Human vs AI gameplay
\end{itemize}

\section{Chess Engine}
C++ implementation with Alpha-Beta algorithm using Disservin library.

\subsection*{Key Components}
\begin{itemize}
    \item {\tt alphabetaBot.cpp} - Main game loop, UCI input, console display
    \item {\tt NodeMove.cpp/h} - Game tree node with alphaBeta() method
    \item {\tt GeneralEvaluator.cpp} - Position evaluation
    \item {\tt OpeningEvaluator.cpp} - Opening heuristics
    \item {\tt EndgameEvaluator.cpp} - Endgame heuristics
\end{itemize}

\section{Connect Four AI}
Neural network AI for Connect Four (7x6 board).

\subsection*{Model}
Input: 42 neurons, Hidden: 64+64+32 (tanh), Output: 1 (linear).

Training: Adam optimizer, MSE loss, Batch=10, Epochs=30, Val=20\%, Test=10\%, Early Stop=5.

\subsection*{Files}
\begin{itemize}
    \item {\tt model.py} - NN model with victory check
    \item {\tt main.ipynb} - Jupyter notebook
    \item {\tt test-case-parser.py} - Test parser
    \item {\tt test/} - Datasets
\end{itemize}

\section{Neural Networks}
\begin{itemize}
    \item {\tt neural\_network/} - Main NN with jsonExtractor
    \item {\tt neural\_network\_jr/} - Junior version
\end{itemize}

\section{Technologies}
C++: Disservin, nlohmann/json, STL. Python: TensorFlow, NumPy, scikit-learn, Jupyter.

\section{Installation}
Compile: g++ implementations/*.cpp traditional\_evaluation/*.cpp -I. -o chess\_engine

Run: ./chess\_engine (UCI notation: e2e4, etc.)

Train Connect Four: cd connect\_four \textbackslash\ and run jupyter notebook main.ipynb or python model.py
