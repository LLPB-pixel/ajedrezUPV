\section{Project Overview}
\textbf{ajedrezUPV} is an AI chess project from UPV. Focus: decision algorithms, heuristic evaluation, game engine programming.

\subsection*{Key Features}
\begin{itemize}
    \item Custom chess engine (C++23)
    \item Alpha-Beta pruning algorithm
    \item UCI notation support
    \item Neural network integration
    \item Modular and extensible code
    \item Human vs AI gameplay
\end{itemize}

\section{Chess Engine}
C++ implementation with Alpha-Beta algorithm using Disservin library.

\subsection*{Key Components}
\begin{itemize}
    \item {\tt src/engine/alphabeta\_bot.cpp} - Main game loop, UCI input, console display
    \item {\tt node\_move.cpp/h} - Game tree node with alphaBeta() method
    \item {\tt general\_evaluator.cpp} - Position evaluation
    \item {\tt opening\_evaluator.cpp} - Opening heuristics
    \item {\tt endgame\_evaluator.cpp} - Endgame heuristics
\end{itemize}

\section{Technologies}
C++: Disservin, nlohmann/json, STL. Python: TensorFlow, NumPy, scikit-learn, Jupyter.

\section{Installation}
CMake: cmake -S . -B build \&\& cmake --build build

Make: make setup \&\& make all

Run: ./bin/alphabeta\_bot (UCI notation: e2e4, etc.)

Connect Four is no longer part of this repository (see \textbf{connectUPV}).
