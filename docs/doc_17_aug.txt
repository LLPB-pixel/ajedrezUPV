ajedrezUPV — Cómo ejecutar el motor de ajedrez
================================================
Fecha: 19 de agosto de 2026

1. COMPILAR
-----------

Opción A (Makefile — más rápido):

    make engine          # Solo compilar el motor
    make all             # Compilar motor + herramientas neuronales
    make test            # Compilar y ejecutar los 52 tests

Opción B (CMake — recomendado):

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build -j$(nproc)
    cd build && ctest    # Ejecutar tests


2. JUGAR
--------

Opción más fácil — script:

    ./play.sh                          # Profundidad 3 (default)
    ./play.sh --depth 5                # Profundidad 5
    ./play.sh --fen "FEN_AQUÍ"         # Desde una posición concreta
    ./play.sh --build                  # Compilar primero y luego jugar
    ./play.sh --help                   # Ver toda la ayuda

Opción directa:

    ./bin/alphabeta_optimized
    ./bin/alphabeta_optimized --depth 5
    ./bin/alphabeta_optimized --fen "rnbqkbnr/pppppppp/8/8/4P3/8/PPPP1PPP/RNBQKBNR b KQkq e3 0 1"
    ./bin/alphabeta_optimized --help


3. COMANDOS DURANTE LA PARTIDA
-------------------------------

    e2e4        Mover pieza (notación UCI: casilla origen + casilla destino)
    e7e8q       Promoción de peón (añadir letra de pieza al final)
    e8g8        Enroque corto
    e8c8        Enroque largo
    d           Mostrar el tablero actual
    fen         Mostrar la posición en formato FEN
    undo        Deshacer los últimos 2 movimientos (tuyo + del motor)
    new         Empezar una partida nueva
    go depth 5  El motor juega buscando a profundidad 5
    quit        Salir del programa (también: q, exit)

El motor juega con blancas por defecto. Tú juegas con negras.
La entrada es case-insensitive (acepta mayúsculas y minúsculas).

5. TESTS
--------

    make test              # Ejecuta los 52 tests (make)
    cd build && ctest      # Ejecuta los 6 suites de tests (cmake)

Todos deben pasar: "ALL TESTS PASSED (0 failures)"

Suites de tests:
  - test_node_move (3 tests): árbol, rebuild, alpha-beta
  - test_search_benchmark (1 test): benchmark depth 1-3
  - test_json_extractor (3 tests): parser JSONL
  - test_json_extractor_junior (3 tests): FEN → tensor
  - test_phase2 (13 tests): TT, búsqueda on-demand, perft, mate-in-N
  - test_e2e (29 tests): end-to-end del motor


6. ENTRENAMIENTO DE LA RED NEURONAL
-------------------------------------

    pip install -r requirements.txt torch
    python python/train.py --data-dir lichess_db --max-chunks 5

Formatos de exportación:
  - models/chess_net_best.pt   (PyTorch checkpoint)
  - models/chess_net.bin       (binario float32 para C++)
  - models/chess_net.json      (compatibilidad con loader C++)


7. REQUISITOS
-------------

- Compilador C++17 (g++ o clang++)
- OpenMP (para paralelización)
- Linux (testeado en Ubuntu/Debian)
- Para entrenamiento: Python 3.8+, PyTorch, numpy, pandas, matplotlib, python-chess


8. MEJORAS APLICADAS
---------------------

Resumen de las principales mejoras incorporadas al código:

Motor de búsqueda:
  [B1] Puntuación correcta de mate (MATE_SCORE - ply)
  [B2] Quiescence search con stand-pat y MVV-LVA
  [B3] Ordenación: TT move, MVV-LVA, killers, history
  [B4] Tabla de transposición 4-way set-associative
  [B5] Profundización iterativa con aspiration windows
  [B6] Búsqueda on-demand (generación lazy de movimientos)
  [B8] SearchResult estructurado (elimina comparación de floats)

Evaluador:
  [E1] Corrección de GameResult (LOSE para jaque mate)
  [E2] control() respeta el parámetro color
  [E3] Bounds en pawn_structure para columnas a/h
  [E4] Peón pasado: comprobación de todas las filas
  [E5] Eliminación de std::clamp
  [E7] safe_king(): fracción de casillas vecinas bajo ataque
  [E9] Evaluación secuencial (sin std::async)

Red neuronal:
  [N1] Inicialización He correcta
  [N2] Pérdida MSE coherente con el gradiente
  [N6] Función objetivo: tanh(cp/400)
  [N7] Perspectiva del lado al mueve
  [N8] Encoding extendido (782 features)
  [N9] Mate scores en el parser
  [N14] Exportación binaria de pesos
  [N16] Entrenamiento en PyTorch
  [N17] Reproducibilidad (seeds fijos, weight decay)
